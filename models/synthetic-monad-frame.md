# Synthetic Monad Frame

## Assertion Provenance

This model is reasserted by Chad Coulter and is used as a dependency within this repository.

## Definition

Any object, grouping, institution, dataset, concept, person, or arbitrary collection can be framed as a Monad-like object for the purpose of resolution.

That framing creates a Monad-like resolution surface.

It does not make the framed thing a Monad.

## Core Invariant

`Defined as Monad-like != Monad`

A synthetic frame may support resolution around an object or grouping without establishing actual Monadhood.

## Lattice Distinction

A synthetic resolution space is not the same thing as either the universal lattice or the actual relative lattice of a Monad.

`Synthetic lattice projection != actual relative lattice`
