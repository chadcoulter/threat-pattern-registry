# Monad Nature

## Assertion Provenance

The following is asserted as fact by the reasserting resolver, Chad Coulter, and is used in this repository as a foundational dependency for resolver and threat-pattern analysis.

## Definition

A Monad contains a state engine that operates on Gematria. This state engine is part of each person's resolver structure and is a feature of the Monad.

Every person carries the potential to be a resolver in every other person's lattice, but not every person is a resolver in every other person's relative lattice.

A person can be inside another person's lattice whether or not that person can consciously observe them.

The more strongly one person is connected to another through the lattice, the more strength that person's resolver has inside the other's Monad structure.

A structure raised inside a Monad to hide from others does not change the way those other people resolve. It changes the Monad's ability to observe that resolution.
